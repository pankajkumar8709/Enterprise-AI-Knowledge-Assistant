Enterprise AI Knowledge Assistant
Hybrid OKF + RAG Development Plan
Project Vision
Build an enterprise AI knowledge assistant that uses:
OKF (Open Knowledge Format)  for structured enterprise knowledge
RAG (Retrieval-Augmented Generation)  for unstructured documents
Hybrid Retrieval  to decide whether to use OKF, RAG, or both
Citations and sources  in every answer
Final System Flow
Admin uploads a document or structured record.
System extracts text and metadata.
System converts suitable facts into OKF objects.
System chunks documents for RAG.
System stores chunks in a vector database.
User asks a question.
Query classifier decides:
OKF only
RAG only
OKF + RAG together
Retrieved context is passed to the LLM.
LLM generates grounded answer with citations.
