1. EXECUTIVE PRODUCT PORTFOLIO OVERVIEW
Nexora Technologies Pvt. Ltd. develops and manages an integrated suite of eight core enterprise SaaS and cloud software products. This document outlines the technical architecture, operational SLAs, licensing tiers, platform dependencies, and lifecycle histories for each product.

PRODUCT ID: PRD-101
PRODUCT NAME: Nexora Cloud
--------------------------------------------------------------------------------
- Product Owner:        Priya Sharma (EMP-1008, Head of Engineering)
- Primary Department:   Engineering (DPT-02)
- Description:          Enterprise-grade Multi-Cloud Infrastructure Management and Orchestration Platform providing automated provisioning, cost optimization, and multi-tenant resource isolation.
- Core Features:
  * Multi-cloud resource abstraction (AWS, GCP, Azure, On-Prem OpenStack)
  * Real-time cloud cost anomaly detection and automated rightsizing
  * Infrastructure-as-Code (IaC) state management and policy enforcement
  * Automated compliance auditing (SOC2, HIPAA, ISO 27001)
- Pricing & Subscription Tiers:
  * Standard Tier: $1,200/month (Up to 50 cloud nodes, 99.9% SLA)
  * Enterprise Tier: $4,500/month (Unlimited nodes, multi-region failover, 99.99% SLA)
  * Dedicated Private Tenant: Custom Quote (Billed annually, dedicated VPC isolation)
- Technical Requirements & Supported Platforms:
  * Supported OS: Ubuntu 20.04+, RHEL 8+, Windows Server 2022
  * Container Runtime: Docker v24.0+, Kubernetes v1.26+
  * Network Requirements: Minimum 1 Gbps egress with TLS 1.3 encryption
- Operational SLA & Support Levels:
  * SLA: 99.99% Monthly Uptime Guarantee with financial credit backing.
  * Support Level: 24/7 Tier-3 Dedicated Support provided by Customer Support (DPT-07).
- Limitations: Maximum 10,000 active concurrent cluster nodes per control plane instance.
- Release History & Versioning:
  * Version 1.0 (Deprecated 2024-03-01): Monolithic control plane. Discontinued.
  * Version 2.2 (Historical 2025-06-15): Introduced AWS/GCP dual-cloud sync.
  * Version 3.1 (Current Active): Kubernetes native, automated FinOps engine.
- Frequently Asked Questions (FAQs):
  Q: Does Nexora Cloud require root access on host instances?
  A: No, Nexora Cloud operates via a non-privileged eBPF agent with read-only host metrics.
